Deactivate voucher type?

Deactivating stops new vouchers of this type being sold online and created by staff. Vouchers already issued are unaffected, and you can reactivate it any time.

Change revenue class?

This changes how vouchers of this type are counted from now on. Vouchers already issued keep the class they were sold under, so past reports will not move — but from here, every new voucher of this type lands in the new class. If the type is currently earning revenue and you move it to a comp or a credit, the revenue line stops growing.
